The reasoning for not moving it in-transaction (would require a `set_workspace_default_team_tx` variant in `workspace_service.rs`, a file outside this diff's scope) is sound. **Recommend filing a follow-up ticket for full atomicity, but not blocking** — no ticket was cited, so this is not a formal deferral, just a non-blocking finding the requester should track.
