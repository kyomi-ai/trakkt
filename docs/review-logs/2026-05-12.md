# Review Log — 2026-05-12

## Feature: TRA-44 — Team-scoped views as tabs on issues page

### Task 1: Schema + Data model
- **SQLite migration missing**: Postgres migration was created but SQLite counterpart was omitted. Fixed by adding matching SQLite migration (without ON DELETE CASCADE per SQLite conventions).

### Task 2: Service + Server functions
- **Missed call site in websocket.rs**: `list_views` gained a new `team_id` parameter but the WebSocket bootstrap call site was not updated. Fixed.

### Task 3: Tab bar UI
- **Raw `<button>` elements**: Tab bar used raw HTML buttons instead of the `<Button>` component. Fixed — now uses `Button` with `Pill`/`PillActive` variants and `GhostMuted`/`IconXs` for the + button.
- **`team_views` closure inside reactive block**: Caused O(n) allocation on every `active_tab` change. Fixed by hoisting to a `Memo` at component level.
- **No `active_tab` reset on team change**: Navigating between teams left stale tab selection. Fixed with Effect that resets to "all" when `resolved_team` changes.
- **Silent JSON parse failure**: `unwrap_or_default()` on view filter deserialization. Fixed with `match` that logs via `tracing::warn!`.
- **Missing focus-visible ring**: Fixed by using `<Button>` component which includes it.

### Task 4: Context menu
- **No click-outside-to-close**: Dropdown stayed open indefinitely. Fixed with document-level `mousedown` listener + `on_cleanup`.
- **`overflow-x-auto` clipping dropdown**: Tab bar's horizontal scroll container clipped absolutely-positioned dropdown. Fixed by replacing with `flex-wrap`.
- **Inline `style=` on rename input**: Overrode `INPUT_CLASS` with inline styles. Fixed with standalone Tailwind classes.
- **Missing ARIA attributes on tab div**: Added `role="tab"` and `tabindex=0` for keyboard accessibility.

### Task 5: Remove old views UI
- Clean removal, zero issues found.

### Patterns to watch for
- Always create SQLite migration alongside Postgres migration
- When changing service function signatures, grep for ALL call sites (including websocket bootstrap)
- Use `<Button>` component for all interactive elements; add focus-visible ring to any exceptions
- Don't put `overflow-x-auto` on containers that have absolutely-positioned dropdown children
- Avoid `unwrap_or_default()` on deserialization — log the error
