# MCP OAuth Authentication

Port Kyomi's OAuth 2.0 flow for MCP client authentication.

## What's needed

1. Database migration: `oauth_clients` table
2. OAuth route handler: `/api/v1/oauth/authorize`, `/api/v1/oauth/token`, `/api/v1/oauth/register`
3. Well-known discovery: `/.well-known/oauth-authorization-server`, `/.well-known/oauth-protected-resource`
4. MCP route: add `www-authenticate` layer, add openid-configuration endpoint
5. KV helpers for OAuth state (auth codes, pending states)

Port from: `apps/server/src/routes/oauth.rs`
