# Add Teams to Trakkt

**Date:** 2026-05-02
**Goal:** Issues belong to teams, not workspaces. Each team has a unique key used as the issue prefix (ENG-42).

## Tasks

### Task 1: Schema + Types + Migration

**Files to create/modify:**

1. `apps/server/migrations/002_add_teams.sql` — Postgres migration:
   ```sql
   CREATE TABLE teams (
       team_id      TEXT NOT NULL PRIMARY KEY,
       workspace_id TEXT NOT NULL REFERENCES workspaces(workspace_id) ON DELETE CASCADE,
       name         TEXT NOT NULL,
       key          TEXT NOT NULL,
       created_at   TEXT NOT NULL,
       UNIQUE(workspace_id, key)
   );
   ALTER TABLE issues ADD COLUMN team_id TEXT REFERENCES teams(team_id);
   ```
   Then backfill: create a default team for each existing workspace using the workspace slug as key, and set team_id on all existing issues.

2. `apps/server/migrations-sqlite/002_add_teams.sql` — Same for SQLite.

3. `crates/trakkt-types/src/models.rs` — Add:
   - `Team { team_id, workspace_id, name, key, created_at }`
   - Add `team_id: String` and `team_key: String` to `Issue`
   - Add `team_key: String` to `IssueWithDetails`

4. `crates/trakkt-types/src/sync.rs` — Add `TEAM` to entity_types constants.

### Task 2: Team Service + Update Issue Service

**Files to create/modify:**

1. `crates/trakkt-auth/src/team_service.rs` — NEW:
   - `create_team(db, workspace_id, name, key, ws) -> Result<Team>`

   - `get_team(db, team_id) -> Result<Team>`
   - `get_team_by_key(db, workspace_id, key) -> Result<Option<Team>>`
   - `get_default_team(db, workspace_id) -> Result<Team>` — returns first team

2. `crates/trakkt-auth/src/lib.rs` — Add `pub mod team_service;`

3. `crates/trakkt-auth/src/issue_service.rs` — Update:
   - `create_issue` takes `team_id` instead of just `workspace_id` for numbering
   - Number generation: `MAX(number) WHERE team_id = $1` (per-team, not per-workspace)
   - Issue INSERT includes `team_id`
   - `get_issue` and `list_issues` JOIN teams to get `team_key`
   - `IssueRow` and `IssueWithNamesRow` gain `team_id` and `team_key`

4. `crates/trakkt-auth/src/auth_service.rs` — Update signup:
   - After creating workspace, create default team with key from workspace slug
   - Pass team_id when creating issues (if any)
