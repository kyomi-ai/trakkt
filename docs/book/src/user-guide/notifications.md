# Inbox & Notifications

Trakkt keeps you informed about changes to issues you care about through the inbox and the My Issues page.

## Inbox

The inbox is your notification feed. It shows events triggered by changes to issues you are involved with -- status changes, new comments, assignment changes, priority updates, and more.

### What triggers a notification

You receive a notification when someone:

- Changes the status of an issue you are watching or assigned to.
- Comments on an issue you are watching or assigned to.
- Assigns you to an issue.
- Changes the priority of an issue you are watching or assigned to.

Each notification shows the actor (who made the change), the event type, the affected issue, and when it happened.

### Filtering and searching

The inbox supports several ways to narrow down what you see:

- **All / Unread** -- toggle between all notifications and only unread ones.
- **Team filter** -- show only notifications from a specific team.
- **Type filter** -- show only a specific notification type (e.g. comments only).
- **Search** -- search notification text to find a specific event.

### Managing notifications

- Click a notification to mark it as read and navigate to the related issue.
- Use **Mark all as read** to clear the unread state on every notification at once.
- Select multiple notifications for bulk actions: mark as read, mark as unread, or delete.
- Deleted notifications can be viewed and restored from the Deleted filter.

Notifications are grouped by time period -- Today, Yesterday, This Week, and Older -- so you can quickly scan what happened recently.

## Watching issues

You automatically watch an issue when you create it, when you are assigned to it, or when you comment on it. You can also manually watch any issue to receive notifications about it.

To watch or unwatch an issue, use the watch toggle on the issue detail page.

## My Issues

The **My Issues** page gives you a personal dashboard of everything on your plate. Issues are grouped into three collapsible sections:

### Assigned to Me

Issues where you are the assignee. This is your primary work queue.

### Created by Me

Issues you created that are not already in the Assigned section. Useful for tracking work you filed but delegated to someone else.

### Watching

Issues you are watching that are not already in the Assigned or Created sections. These are issues you want to keep an eye on without being directly responsible.

Each section can be collapsed or expanded, and the collapse state is persisted across sessions. All three sections support the same sorting and filtering as the main issue list -- you can filter by status, priority, or search by text.
