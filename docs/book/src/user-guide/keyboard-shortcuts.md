# Keyboard Shortcuts

Trakkt is designed for keyboard-first interaction. Most common actions have a shortcut so you can navigate and manage issues without reaching for the mouse.

## Global shortcuts

These work from anywhere in the application.

| Shortcut | Action |
|----------|--------|
| `Cmd+K` / `Ctrl+K` | Open the command palette |
| `Escape` | Close the current modal, palette, or popover |

## Command palette

The command palette is a quick-access overlay for searching and navigating. Press `Cmd+K` (macOS) or `Ctrl+K` (Linux / Windows) to open it, then start typing to search for issues by title or identifier. Use the arrow keys to navigate results and `Enter` to jump to the selected item.

Press `Escape` to close the palette.

## Issue list shortcuts

These shortcuts are active when you are on any issue list.

| Shortcut | Action |
|----------|--------|
| `j` | Move selection down |
| `k` | Move selection up |
| `Enter` | Open the selected issue |
| `c` | Create a new issue |

The current selection is highlighted visually, so you always know which issue will open when you press `Enter`.

## Dropdown and popover navigation

When a dropdown or popover is open (for example, the status or priority picker), you can use:

| Shortcut | Action |
|----------|--------|
| Arrow Up / Arrow Down | Move through options |
| `Enter` | Select the highlighted option |
| `Escape` | Close the dropdown without changing the value |

## When shortcuts are disabled

Keyboard shortcuts are automatically disabled when your cursor is inside a text input, textarea, or the description editor. This prevents shortcuts from interfering with your typing -- pressing `j` in a comment box types the letter `j` rather than moving the issue selection.

Shortcuts re-activate as soon as focus leaves the text field.
