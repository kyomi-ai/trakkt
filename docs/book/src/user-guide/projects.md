# Projects & Milestones

Projects let you group related work that spans multiple teams or represents a larger initiative. Within each project, milestones mark key checkpoints along the way.

## Creating a project

1. Open the **Projects** section from the sidebar.
2. Click **New Project**.
3. Fill in the details:
   - **Name** -- a clear name like "Q3 Launch" or "Mobile App".
   - **Description** -- optional context about the project's goals and scope.
   - **Status** -- the current state of the project (see below).
   - **Lead** -- the workspace member responsible for driving the project.
   - **Start date** and **Target date** -- optional date range for the project timeline.
   - **Icon and color** -- visual identifiers that appear in the sidebar and on issue cards.

## Project statuses

Projects have their own status, separate from issue statuses. The available statuses are:

| Status | Meaning |
|--------|---------|
| **Planned** | Defined but not yet started. |
| **In Progress** | Actively being worked on. |
| **Paused** | Temporarily on hold. |
| **Completed** | All planned work is finished. |
| **Cancelled** | The project was abandoned. |

You can change a project's status at any time from the project detail page.

## Milestones

Milestones are checkpoints within a project. Use them to break a project into phases, releases, or deadlines.

### Creating a milestone

1. Open the project detail page.
2. Navigate to the **Milestones** section.
3. Click **Add Milestone**.
4. Enter a name, an optional description, and an optional target date.

Milestones are ordered within their project, so you can arrange them in the sequence they should be completed.

### Assigning issues to milestones

When editing an issue, you can assign it to both a project and a milestone within that project. This tells the team which release or deadline the issue is targeting.

## Assigning issues to projects

Any issue from any team can be assigned to a project. Open the issue detail page and select a project from the project dropdown. If the project has milestones, you can also select a specific milestone.

An issue can belong to at most one project and one milestone at a time.

## Progress tracking

Each project's detail page shows a progress summary computed from its issues' status categories:

- **Total issues** -- how many issues are assigned to the project.
- **Completed** -- issues in a completed status.
- **Cancelled** -- issues in a cancelled status.
- **Percent done** -- the ratio of completed or cancelled issues to total issues.

This gives you a quick health check on any project without having to count issues manually.
