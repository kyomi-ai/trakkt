Speed as Design

"Faster than anything else." Every design decision serves perceived performance.

Optimistic UI

Show the result before the server confirms. Status changes, issue creation, comment posting update immediately. Roll back on error.

Non-Blocking Animations

Content appears immediately. Transitions layer on top. Max 200ms for state changes. No entrance animations that gate content.

Keyboard-First

Every action reachable by keyboard. j/k, single-key shortcuts, Cmd+K palette. The mouse is optional.

No Spinners Under 100ms

Brief loading indicators only appear after 100ms delay. Most operations feel instant.

Content Before Chrome

Issue data renders before sidebar animations complete. Data first, nav second, decorative last.

Zero Layout Shift

Reserve space for async content. Sidebar state persists. No content jumping after load.

Buttons

Compact. DM Sans 13px weight 600. 6px radius.

Dropdowns

Compact triggers show current value with icon. Click to expand a searchable, keyboard-navigable menu.

COLLAPSED TRIGGERS
Triggers with a value show the icon + label. Empty triggers show the field name. Chevron indicates expandable.
